## 已知限制（设计内）

| # | 项 | 说明 |
|---|---|---|
| L1 | 模型层不随制品 | 许可 UNKNOWN/厂商二进制；恢复基线只到驱动可加载，模型层按 INSTALL §7 手动部署 |
| L2 | 恢复镜像不含用户数据 | /home 用户文件、凭据、自装软件不在 Level A；这是恢复基线的边界 |
| L3 | 温度监控 NOT_AVAILABLE | 板上 thermal 接口不可读（历史状态），P8 以 CmaFree/IRQ/内存为稳定性指标 |
| L4 | 单模型串行约束 | 模型服务设计禁止并发加载两个大模型（807.7M + 1640.8M 与 cma=2048M 预算） |
| L5 | l1 为手动菜单项 | 默认 l0（保守）；NPU 需在 U-Boot 菜单手动选 l1。自动切 l1 需单独决策（非本版范围） |
| L6 | idblock 文件/磁盘形态差异 | 板端 sector64 直读哈希 ≠ MiniLoaderAll 文件哈希（RK3588 idblock 磁盘形态含编码，属正常）；已用双锚点核验（uboot 逐字节 + 板端原始 idblock dump 另存） |
